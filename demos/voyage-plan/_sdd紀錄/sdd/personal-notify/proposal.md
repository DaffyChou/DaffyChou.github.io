# 提案：通知方式改為「依人」（personal-notify）

- 類型：規則修正（通知層由「全船隊×維度」改為「個人×維度」）
- 建立日期：2026-09-17
- 來源：使用者確認（2026-09-17）——通知方式都是依據人，不會互相影響；預設全部開啟，由主管、組員或代理人自己決定是否關閉；關閉的是通知，不是偵測。

## 規則（已確認）
1. **通知管道只屬於人**：每位使用者（主管、組員、代理人）各有一份「我的通知方式」，彼此獨立、互不影響。閾值仍對船；偵測永遠進行，**關閉通知不等於關閉偵測**（事件照樣立案、畫面照樣顯示）。
2. **預設全部開啟**（Mail＋LINE，所有維度）；使用者只需要決定要不要關掉某些。
3. 可「統一設定」（所有維度一次）也可「個別設定」（某維度不同）；個別優先於統一。
4. 不再有「全船隊層的通知方式」，主管的「統一設定」也只影響主管自己；主管不能替組員關通知。
5. 收件人＝該船的監管人員；代理人在授權期間也收授權者船舶的通知，用代理人自己的設定。
6. 變更寫入變更紀錄（layer=notify、scope=本人）。

## 畫面
- 集體設定頁頁首：改為「我的通知方式 · 統一設定：☑ Mail ☑ LINE」（所有人都看得到、只影響自己），旁註「關閉只影響通知，偵測與事件不受影響」。原「全船隊統一設定」移除。
- 各維度列「通知 / Notify」：改為每個人自己的個別設定（所有角色皆可勾），與統一不同時標「已自訂」，可「沿用統一」；不再有「全船隊層 · 唯讀」。
- 單船設定頁維度列同上（同一份個人設定，跨船共用；通知本來就是對人不對船）。
- 事件／通知橫幅（Demo）：依收件人有效管道顯示「已通知：Mail／LINE」。

## 影響範圍
- 移除 `_thresholds[dim].notify` 的使用（保留欄位相容舊資料，不再讀）；新增 `_userNotify[user] { all: {mail,line}, dims: {dim:{mail,line}} }`（key `slab_va_user_notify_v1`，預設全開）、`effectiveNotifyFor(user, dim)`；`dimRowHTML` 通知區塊、頁首統一列、`wireDurationAndNotify` 通知分支、事件通知呈現；規範頁 §3／§4、流程頁、Q&A、截圖。
