## 驗收條件

- 情境：威明輪在海上航段，全船隊預設海上航段 W≥1、單船常設海上航段 W≥2，偏移 1.5 → 不發警報；船舶詳情顯示來源「單船／海上航段」。
- 情境：同上但單船只設「全航段通用 W≥2」→ 仍不發警報（單船通用優先於全船隊專屬）。
- 情境：單船只填 W 未填 C，超過全船隊預設的 C → 發 Critical；來源標示 W＝單船、C＝全船隊。
- 情境：對威明輪設時效覆寫 W≥3（有效期到明天），偏移 2.5 → 不發警報；把系統時間撥到後天 → 回到 L2／L4 規則並發 Warning，變更紀錄出現一筆 by system 的到期紀錄。
- 情境：以組員登入，閾值頁的全船隊預設與區域覆寫為唯讀，集體設定範圍選單沒有「全船隊」；只能對自己的船寫入單船／時效設定。
- 情境：以主管登入修改全船隊預設航線偏移，confirm 顯示「影響 N 艘、其中 M 艘因單船覆寫不受影響」；套用後有覆寫的船閾值不變。
- 情境：主管在閾值頁選「組員 A」，只列出 A 的船與 A 設定過的覆寫，每筆有設定者與時間。
- 情境：組員在單船設定頁看圍籬，沒有刪除按鈕，只能停用此船或改提醒距離／船速；停用後其他船的該圍籬監控不受影響。
- 情境：任何一次寫入後，變更紀錄面板可查到該筆的舊值、新值、層級與操作者。
- 情境：以主管登入，集體設定選「依監管人員的船隊 → 監管 B」套用 W≥2，監管 B 的每艘船單船覆寫皆出現該值，其他監管的船不變。
- 情境：五頁在桌面與手機皆無 console 錯誤，深淺色正常，右上角橫幅與面板不交疊。
