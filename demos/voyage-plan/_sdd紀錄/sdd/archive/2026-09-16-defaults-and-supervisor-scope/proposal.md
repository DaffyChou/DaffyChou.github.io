# 提案：移除主管批次清除組員覆寫 ＋ 未設定時顯示「系統預設」與預設值依據（defaults-and-supervisor-scope）

- 類型：新功能（規則調整 ＋ 顯示補強）
- 建立日期：2026-09-16
- 來源：客戶回覆（2026-09-16）
  1. 主管（組經理）實務上管的是監管人員而非船，主管設定少用；先把「可以清除組員的覆寫」移除。
  2. 全船隊預設尚未設定時，徽章與設定頁要顯示「系統預設」；並說明這些預設值是依據哪些船舶營運慣例與法規訂的。

## 為什麼做

前案讓主管能一次清掉某組員全部船的單船設定，與客戶的分工不符（主管不直接調船的閾值）。另外系統原廠值與主管設過的全船隊值在畫面上長得一樣，使用者分不清「有人決定過」還是「系統假設」；且原廠值目前只是 Demo 假設，需要交代依據並提醒上線前由公司確認。

## 要改什麼

### A. 主管不能清組員的覆寫（2026-09-16 選項 C）
- 集體設定的套用對象**保留**「全船隊預設」與「依監管人員的船隊」；主管仍可用後者逐船寫入值。
- 主管視角移除所有「清除組員覆寫」的入口：
  - 集體設定「依監管人員的船隊」範圍下的「清除此航段所有設定」按鈕隱藏；`resetBatchSegment` 對主管的 byMgr 分支直接拒絕。
  - 單船設定頁：主管看不到「清除此航段所有設定」、每維度列的「復原」，以及時效性覆寫的「移除」、圍籬單船層的「清除覆寫」（這些都是清組員的個別設定）。
  - 主管在單船設定仍可**修改**值（寫入新值、新增時效覆寫、停用此船），設定者記為主管。
- 「全船隊預設」範圍的「清除此航段所有設定」保留（只重置 L4 回系統預設，不碰任何組員設定）。
- 組員自己（含有效代理授權的代理人）對自己船的復原／清除不變。
- 權限碼：新增 `threshold.vessel.clear.own`（組員／代理人有）、不給主管 `threshold.vessel.clear.any`；系統管理員同主管。

### B. 「系統預設」顯示
- 資料層：`_thresholds[dim]` 記錄是否曾由人設定（有 `by/at` 即為「已設定」；航段專屬格同理）。解析器回傳來源時，L4 若從未設定則來源為 `system`（不再併入 global）。
- 徽章：從未設定時顯示 <span>生效 系統預設·通用</span>（灰色、虛線框），主管填過才顯示「全船隊·通用」。
- 集體設定「全船隊預設」分頁：每個維度列「預設」欄旁顯示「系統預設 ⓘ」，tooltip 列出該值的依據；頁首加提示「有 N 個維度尚未設定，目前使用系統預設值；上線前請依公司 SMS／營運規範確認」。
- 單船設定的「預設」欄同樣區分「系統預設」與「全船隊」。

### C. 預設值依據（DEFAULT_THRESHOLD_BASIS）
每個維度附一段「依據」文字（顯示於 tooltip 與說明頁），內容為業界慣例與相關規範的**建議來源**，數值本身仍需客戶確認：

| 維度 | Demo 預設 | 建議依據 |
|---|---|---|
| 航線偏移 W 1.5／C 3 NM | 航行計畫的 cross-track 安全範圍 | IMO Res. A.893(21) 航行計畫指南要求為每段航線訂 XTD 限值（safety margin）；業界常以 Safety Frame 的 50%／100% 作 W／C；本 Demo 亦顯示航線計畫帶入的「計畫」值供參考 |
| 速度異常 W 20%／C 40% | 與計畫配速的偏差比例 | 租約（charter party）速度條款與 Noon Report 慣例：偏離配速 10–20% 視為需說明；本值為營運端經驗值，非法規 |
| 海氣象預警 W 0.65／C 0.85（海況指數） | 氣象警報等級 | 對應 StormGeo／WMO 海況等級與公司「重風險天氣迴避」內規（例如顯著波高 4 m／6 m、蒲福風級 7／9）；指數化後由客戶對照 |
| 主機異常 W 78／C 93（分數） | 機艙監測 | 依主機廠商 OEM 警戒值（RPM、排氣溫度、滑油壓）與 PMS 規範；分數為 Demo 抽象值，正式需對接輪機資料 |
| 漂航圈半徑 W／C（NM） | 錨泊安全 | 拖錨判定慣例：迴旋半徑 ≈ 船長 ＋ 出鏈長度（水深 × 3–5 倍），W 取迴旋圈外緣、C 取其 1.5–2 倍；參考 IMO 錨泊操作指引與船長常規 |
| 到離港 W 5／C 0.5 NM | 港界與引水站 | 以港區界線／引水登船點距離為準（各港不同），W 為預先通報距離、C 為進入港界 |
| 到離區域 預設 5 NM | 風險區邊界 | 依 NAVTEX／NOTAM 警戒區慣例，接近邊界前 N 海浬預警；軍演區以公告範圍為準 |
| 持續時間 60／3 分 | 誤報抑制 | AIS 回報週期（航行中 2–10 秒、慢速 3 分）與位置抖動；Warning 需持續一段時間避免瞬時尖峰，Critical 較短以利即時處置 |

正式系統建議：預設值由公司 SMS（安全管理系統）或船隊營運手冊定義後，於部署時寫入 L4 並記錄設定者；系統原廠值只作為安裝後的保底。

## 影響範圍
- `voyage-alert-rwd-merged.html`：`renderBatchBySegmentSetup`（移除 byMgr radio 與相關狀態）、`resetBatchSegment`／`commitBatchRow`／`applyBatchChanges`（移除 byMgr 分支）、`renderPerVesselSetup`（主管視角隱藏「清除此航段所有設定」）、`getEffectiveThreshold`（system 來源）、`THRESHOLD_SOURCE_META`／徽章、`dimRowHTML`（預設欄標示與 tooltip）、新增 `DEFAULT_THRESHOLD_BASIS`、集體設定頁首提示。
- 文件：規範頁 §3 矩陣與 §4 寫入規則、操作流程頁主管第 3／4 步與情境 2、截圖版流程頁、Q&A 頁 Q2／Q3 補「系統預設」說明。

## 已確認（2026-09-16）
1. 選項 C：主管完全不能清組員的覆寫（批次清除、單船頁清除、單列復原、時效移除、圍籬清除覆寫對主管全部隱藏），但仍可改值；「依監管人員的船隊」範圍保留。
2. 「系統預設」的依據文字以上表為準，數值仍標示「需公司確認」。
